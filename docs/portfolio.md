# Presenting this project

**Suggested title:** Financial education resource index

**Short description for Contra:** I built a Python scraper that organizes a public financial education directory into a structured CSV. It records categories, resource names, source domains, and links, then creates a simple report that makes the collection easy to review. This was an independent portfolio project using publicly listed resources.
